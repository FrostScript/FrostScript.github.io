1. 前向传播 (Forward): 预测结果
y = w * x + b    → y = 0.5
2. 计算损失 (Loss): 预测有多准？
Loss = (y - t)²   → Loss = 2.25
3. 反向传播 (Backward): 找到参数优化的方向
计算损失对每个参数的“影响程度”（梯度）:
dL/dy = 2 * (y - t)   → -1.5
dL/dw = (dL/dy) * x   → -1.5
dL/db = (dL/dy) * 1   → -1.5
4. 梯度下降 (Update): 更新参数，让模型更聪明
新w = w - 学习率 * (dL/dw)
新b = b - 学习率 * (dL/db)
例如: 学习率 lr = 0.1
更新后: w = 0.65, b = 0.15
学习步骤
1. 预测: 根据 w, b 计算出 y。
2. 评估: 计算 y 和 t 的差距(Loss)。
3. 反思: 计算改变 w, b 对 Loss 的影响。
4. 学习: 朝着缩小 Loss 的方向微调 w, b。
核心词汇
Loss
Gradient
Learning Rate
提示: 这个简单的模型 y = w*x + b 是所有复杂神经网络的基础。
