# 数学建模常用模型速查手册

本文档梳理数学建模中常见的模型，并提供一个快速参考。

---

## 第一部分：模型速查总表

| 模型类别 | 模型名称 | 主要使用场景 | 核心特征 |
| :--- | :--- | :--- | :--- |
| **优化算法** | **线性规划 (LP)** | 资源分配、生产计划、成本最小化 | 目标函数和约束条件均为 **线性**，求解效率高。 |
| | **整数规划 (IP/MIP)** | 变量含整数的决策问题（如选址、调度） | LP的扩展，决策变量部分或全部为整数，计算复杂度高。 |
| | **0-1规划** | “是/否”类型的决策问题（如项目选择、背包问题） | 特殊的整数规划，变量仅取0或1。 |
| | **非线性规划 (NLP)** | 目标或约束为非线性函数（如工程设计、金融投资组合） | 更贴近现实，但可能存在局部最优解，求解困难。 |
| | **动态规划 (DP)** | 多阶段决策过程优化 | 将问题分解为最优子结构，利用状态转移方程求解。 |
| | **目标规划 (GP)** | 多目标决策，在资源有限下使各目标尽可能接近期望值 | 适用于多目标冲突场景，寻找“满意解”而非单一“最优解”。 |
| | **二次规划 (QP)** | 目标函数是二次函数，约束是线性的优化问题 | 广泛用于投资组合优化（最小化方差）。 |
| | **随机规划** | 涉及不确定性（随机变量）的优化问题 | 在不确定环境下做最优决策，如库存管理、能源规划。 |
| | **网络流模型** | 网络中的流量分配与优化（如最大流、最小费用流） | 基于图论，解决物流、通信网络中的流量问题。 |
| | **旅行商问题 (TSP)** | 寻找访问N个城市并返回出发点的最短路径 | 经典的组合优化问题，NP-hard问题。 |
| | **车辆路径问题 (VRP)** | 为一组车辆规划最优配送路线 | TSP的扩展，考虑车辆容量、配送时间窗等。 |
| | **遗传算法 (GA)** | 复杂优化问题的启发式搜索 | 模拟自然选择和遗传机制，全局搜索能力强，但可能早熟。 |
| | **模拟退火 (SA)** | 全局优化问题的随机搜索算法 | 模拟固体降温过程，允许在一定概率下接受劣质解以跳出局部最优。 |
| | **蚁群算法 (ACO)** | 在图中寻找最优路径的概率性算法 | 模拟蚂蚁觅食行为，通过信息素正反馈协作寻优。 |
| | **粒子群算法 (PSO)** | 模拟鸟群觅食行为的群体智能优化算法 | 通过个体和群体经验更新自身位置和速度来寻找最优解。 |
| **评价与决策**| **层次分析法 (AHP)** | 对多准则、分层决策问题进行权重计算和方案排序 | 将定性问题定量化，通过构建判断矩阵计算权重，主观性较强。 |
| | **网络分析法 (ANP)** | AHP的扩展，考虑了指标间的相互依赖和反馈关系 | 更真实地反映复杂决策系统中各元素间的相互作用。 |
| | **TOPSIS法** | 通过计算与最优、最劣解的距离进行多方案排序 | 思路简单直观，对数据分布无特殊要求。 |
| | **VIKOR法** | 在多准则决策中提供折衷解，侧重于冲突下的妥协 | 同时考虑最大化群体效益和最小化个体遗憾。 |
| | **ELECTRE** | 基于“超越关系”对方案进行排序的决策方法 | 处理不确定性和模糊性较强，但结果可能无唯一解。 |
| | **PROMETHEE** | 基于优先函数定义方案间的优先流，进行排序 | 比ELECTRE更易于理解和使用，参数设置灵活。 |
| | **熵权法 (EWM)** | 客观地确定多指标评价体系中的指标权重 | 根据指标数据的变异程度（信息熵）来赋权，避免主观性。 |
| | **CRITIC法** | 综合指标的变异性和冲突性来客观赋权 | 同时考虑了每个指标内部的对比强度和指标间的冲突。 |
| | **模糊综合评价** | 处理评价指标和标准模糊不清的决策问题 | 基于模糊数学，适用于定性指标的量化评估。 |
| | **灰色关联分析(GRA)**| 分析系统内各因素之间关联度的强弱 | 根据序列曲线的几何形状相似度来判断关联程度。 |
| | **DEMATEL** | 识别和分析复杂系统中各因素间的因果关系和影响度 | 通过构建直接影响矩阵，计算影响度与被影响度。 |
| | **数据包络分析(DEA)**| 评价多输入、多输出的“部门”或“单位”的相对效率 | 非参数方法，无需预设函数形式，常用于评价医院、银行等效率。 |
| | **成本效益分析(CBA)**| 评估项目的投入（成本）与产出（效益）是否值得 | 将所有成本和效益货币化，计算净现值或内部收益率。 |
| | **博弈论模型** | 分析多个决策主体在策略互动中的行为和均衡 | 如囚徒困境、纳什均衡，用于市场竞争、谈判等分析。 |
| | **效用理论** | 描述决策者在不确定性下的偏好和风险态度 | 为决策者的选择提供理论基础。 |
| **统计与概率**| **描述性统计** | 总结和呈现数据基本特征（均值、中位数、方差等） | 数据分析的第一步，了解数据概况。 |
| | **假设检验** | 判断样本与总体、或样本与样本之间差异是否显著 | 如t检验、Z检验、F检验。 |
| | **t检验** | 检验两个正态分布总体的均值是否存在显著差异 | 分为单样本、独立样本、配对样本t检验。 |
| | **方差分析 (ANOVA)** | 检验两个或以上样本均值是否存在显著差异 | t检验的扩展，分析类别自变量对数值因变量的影响。 |
| | **卡方检验 (Chi-Squared)** | 检验两个分类变量是否独立 | 用于分析列联表数据，如吸烟与患病是否相关。 |
| | **相关性分析** | 衡量两个或多个变量之间的线性关系强度和方向 | Pearson（线性）、Spearman（等级）、Kendall（等级）。 |
| | **主成分分析 (PCA)** | 将多个相关变量转化为少数几个不相关的综合变量（主成分） | 数据降维技术，提取主要信息，解决多重共线性。 |
| | **因子分析 (FA)** | 从多个原始变量中提取潜在的、不可观测的公共因子 | 也是降维方法，但更侧重于解释变量间的内部结构。 |
| | **线性回归** | 用线性关系模型拟合一个或多个自变量与因变量的关系 | 模型简单，解释性强，是所有回归模型的基础。 |
| | **多项式回归** | 线性回归的扩展，用于拟合非线性关系 | 通过引入自变量的高次项实现。 |
| | **岭回归/Lasso回归** | 带有正则化的线性回归，用于处理多重共线性和特征选择 | 岭回归用于收缩系数，Lasso回归可将某些系数收缩至0。 |
| | **逻辑回归** | 用于预测二分类或多分类结果（如：是/否，A/B/C） | 输出是概率，广泛用于分类问题。 |
| | **泊松分布/回归** | 描述和预测单位时间内事件发生的次数 | 如预测一小时内到达银行的顾客数。 |
| | **贝叶斯定理/网络** | 在已知先验信息下，更新事件发生的概率 | 用于垃圾邮件过滤、医疗诊断等。 |
| | **马尔可夫链** | 描述状态转移过程，未来状态仅与当前状态有关 | 用于预测天气变化、顾客流失、市场占有率转移。 |
| **预测与时序**| **移动平均法** | 通过计算时间序列的滚动平均值来平滑和预测 | 简单，但对趋势变化反应滞后。 |
| | **指数平滑** | 对历史数据赋予递减的权重进行加权平均（SES, Holt, Holt-Winters） | 相比移动平均，对近期数据更敏感，可处理趋势和季节性。 |
| | **ARIMA模型** | 自回归差分移动平均模型，经典的时间序列预测方法 | 将平稳时间序列拟合为AR和MA模型的组合。 |
| | **SARIMA模型** | 季节性ARIMA模型，ARIMA的扩展 | 增加了对数据中季节性变化的处理。 |
| | **ARCH/GARCH模型** | 用于建模和预测金融时间序列的波动性（方差） | 描述了收益率的波动聚集现象。 |
| | **灰色预测 (GM(1,1))**| “少数据”、“贫信息”情况下的趋势预测 | 对数据量要求小，适合于短期、中期的指数增长趋势预测。 |
| | **Prophet模型** | Facebook开源的时间序列预测工具 | 易于使用，能自动处理节假日效应和季节性，对缺失值稳健。 |
| | **向量自回归(VAR)**| 多变量时间序列预测模型，捕捉变量间的动态影响 | 将每个变量都视为其他所有变量滞后项的函数。 |
| | **状态空间模型** | 用潜在的、不可观测的“状态”变量来描述系统的时间演化 | 框架灵活，卡尔曼滤波是其重要应用。 |
| | **卡尔曼滤波** | 在含噪声的测量数据中，估计动态系统的最优状态 | 广泛用于导航、信号处理和控制领域。 |
| | **灾变理论** | 研究系统从稳定状态到另一稳定状态的“突变”现象 | 用于解释和预测如桥梁坍塌、市场崩溃等突变行为。 |
| **机器学习**| **K-Means聚类** | 将样本数据自动划分为K个类别 | 简单高效，但需预先指定类别数K，且对初始点敏感。 |
| | **层次聚类** | 通过构建树状的聚类结构（谱系图）进行聚类 | 无需预设聚类数，但计算复杂度高。 |
| | **DBSCAN** | 基于密度的聚类算法，能发现任意形状的簇 | 无需指定簇数，能有效处理噪声点。 |
| | **支持向量机 (SVM)** | 通过寻找最大间隔超平面来进行分类或回归 | 在高维空间中表现优异，特别适合小样本、非线性问题。 |
| | **K-近邻 (KNN)** | 通过寻找最近的K个邻居的类别来决定新样本的类别 | 思想简单，无需训练，但预测时计算量大。 |
| | **朴素贝叶斯** | 基于贝叶斯定理和特征条件独立假设的分类器 | 计算简单高效，在文本分类等领域效果好。 |
| | **决策树** | 通过树状结构进行决策的分类和回归模型 | 模型直观，易于解释，但容易过拟合。 |
| | **随机森林 (RF)** | 通过集成多个决策树来进行分类和回归 | 决策树的“进化版”，通过Bagging减少过拟合，提高精度。 |
| | **梯度提升机 (GBM)** | 通过迭代地训练决策树来修正前一棵树的残差 | 集成学习的代表，预测精度高。 |
| | **XGBoost/LightGBM** | GBM的高效工程实现，速度更快、性能更好 | 目前竞赛和业界最常用的机器学习模型之一。 |
| | **人工神经网络(ANN)**| 模拟人脑神经元结构的计算模型 | 学习能力强，能拟合任何复杂函数。 |
| | **卷积神经网络(CNN)**| 专门处理网格结构数据（如图像）的深度学习模型 | 通过卷积核和池化层有效提取空间特征。 |
| | **循环神经网络(RNN)**| 专门处理序列数据（如文本、时间序列）的模型 | 网络中的循环结构使其具有“记忆”功能。 |
| | **LSTM/GRU** | RNN的变体，用于解决长序列依赖和梯度消失问题 | 目前处理序列数据的标准模型。 |
| | **Transformer** | 基于自注意力机制的深度学习模型，完全替代了RNN | 在自然语言处理（NLP）领域取得巨大成功，如BERT, GPT。 |
| | **Q-Learning** | 无模型的强化学习算法，用于学习动作-价值函数 | 代理（Agent）通过与环境交互，学习在特定状态下执行哪个动作能获得最大回报。 |
| | **Agent-Based Modeling (ABM)** | 通过模拟大量自主智能体（Agent）的行为及其相互作用来研究系统宏观现象 | 自下而上的建模思路，用于模拟社会、经济、生态等复杂系统。 |
| **图与网络**| **Dijkstra算法** | 单源最短路径算法，不能处理负权边 | 贪心策略，每次选择离源点最近的未访问节点。 |
| | **Floyd-Warshall算法** | 计算图中任意两点间的最短路径 | 动态规划思想，适用于稠密图，可处理负权边。 |
| | **A* 搜索算法** | 带有启发式函数的Dijkstra算法，更高效地寻找最短路径 | 在游戏寻路、地图导航中常用。 |
| | **Prim/Kruskal算法**| 最小生成树算法，用最小成本连接所有节点 | 用于网络建设、布线等场景。 |
| | **PageRank算法** | 谷歌用于评估网页重要性的算法 | 基于链接分析，一个网页被越多重要网页链接，它就越重要。 |
| | **社区发现算法** | 在复杂网络中识别出内部连接紧密、外部连接稀疏的节点群组 | 如Louvain算法，用于社交网络分析、生物网络功能模块识别。 |
| | **网络中心性分析** | 衡量网络中节点重要性的指标 | 度中心性（连接数）、介数中心性（桥梁作用）、紧密中心性（到其他节点的平均距离）。 |
| | **PERT/CPM** | 项目管理技术，用于规划、调度和控制项目进度 | 通过分析任务依赖关系，找到关键路径，估算项目工期。 |

## 第二部分：各模型详细介绍

### **优化算法 (Optimization Algorithms)**

#### 1. 线性规划 (Linear Programming, LP)
- **简介**: 在线性等式或不等式约束下，求解一个线性目标函数最大值或最小值的问题。
- **使用场景**: 生产计划、资源分配、运输问题、营养配餐。
- **优点**: 理论成熟，有高效算法（单纯形法、内点法），总能找到全局最优解。
- **缺点**: 要求问题必须是严格线性的，现实中很多问题需要简化才能应用。
- **关键要素**: 决策变量、目标函数、约束条件。

#### 2. 整数规划 (Integer Programming, IP/MIP)
- **简介**: 决策变量部分或全部被限制为整数的线性规划。
- **使用场景**: 选址问题、人员调度、固定成本问题、项目选择。
- **优点**: 能精确刻画离散决策，应用场景比LP更广。
- **缺点**: 计算复杂度是NP-hard，求解大规模问题非常耗时。
- **关键要素**: 同LP，但需明确整数或0-1变量。

#### 3. 0-1规划 (0-1 Programming)
- **简介**: 整数规划的特例，所有决策变量只能取0或1。
- **使用场景**: 背包问题（物品选或不选）、任务分配（某人做或不做某事）。
- **优点**: 非常适合描述“是/否”类型的决策。
- **缺点**: 组合爆炸问题，当变量增多时，可能解空间巨大。
- **关键要素**: 0-1决策变量、目标函数、约束条件。

#### 4. 非线性规划 (Non-Linear Programming, NLP)
- **简介**: 目标函数或约束条件中至少有一个是非线性函数的优化问题。
- **使用场景**: 工程设计（如结构尺寸优化）、金融投资组合（如Markowitz模型）、机器学习模型求解（如SVM）。
- **优点**: 能更真实地反映现实世界中的非线性关系。
- **缺点**: 求解困难，没有通用解法，可能陷入局部最优解，计算复杂度高。
- **关键要素**: 决策变量、非线性目标函数、非线性或线性约束。

#### 5. 动态规划 (Dynamic Programming, DP)
- **简介**: 将复杂问题分解为一系列相互关联的子问题，通过求解子问题来得到原问题的解。
- **使用场景**: 背包问题、最短路径问题、资源管理、库存控制。
- **优点**: 保证找到全局最优解，算法思想巧妙，效率高。
- **缺点**: 要求问题必须满足“最优子结构”和“无后效性”，设计状态和状态转移方程是难点。
- **关键要素**: 阶段、状态、决策、状态转移方程、最优性原理。

#### 6. 目标规划 (Goal Programming, GP)
- **简介**: 适用于多目标决策的优化方法。当多个目标无法同时最优时，它致力于最小化各目标与其期望值之间的偏差。
- **使用场景**: 企业在制定生产计划时，既想利润最大化，又想成本最小化，还想市场占有率最高。
- **优点**: 能有效处理多目标冲突问题，提供一个“满意解”而非单一“最优解”，更符合管理决策实际。
- **缺点**: 需要为每个目标设定期望值和优先级，带有一定主观性。
- **关键要素**: 决策变量、偏差变量（正负偏差）、目标约束（用偏差表示）、优先因子和权重、目标函数（最小化偏差的加权和）。

#### 7. 二次规划 (Quadratic Programming, QP)
- **简介**: 目标函数是二次函数，而约束条件是线性的规划问题。
- **使用场景**: 投资组合优化（在给定预期收益下，最小化投资组合的方差/风险）、约束最小二乘问题。
- **优点**: 若目标函数是凸的，则可以找到全局最优解。
- **缺点**: 若目标函数非凸，则可能存在多个局部最优解。
- **关键要素**: 决策变量、二次目标函数、线性约束。

#### 8. 随机规划 (Stochastic Programming)
- **简介**: 用于在存在不确定性（即部分参数为随机变量）的情况下做出最优决策的优化框架。
- **使用场景**: 库存管理（未来需求不确定）、电力系统规划（发电量和负荷不确定）、金融投资（资产回报率不确定）。
- **优点**: 能在不确定性环境下制定更稳健、风险更低的决策。
- **缺点**: 模型复杂，求解难度大，需要对随机变量的概率分布有较好的假设。
- **关键要素**: 决策变量、随机参数及其概率分布、多阶段决策结构。

#### 9. 网络流模型 (Network Flow Model)
- **简介**: 在有向图中，模拟物质、信息或能量从源点流向汇点的过程，并进行优化。
- **使用场景**: **最大流问题**（输油管道网络的最大输送能力）、**最小费用流问题**（在满足流量要求下成本最低的运输方案）。
- **优点**: 模型直观，有高效的多项式时间算法（如Ford-Fulkerson, Edmonds-Karp）。
- **缺点**: 只能应用于可以抽象为网络流结构的问题。
- **关键要素**: 图（节点、弧）、弧的容量限制、费用函数、流量平衡约束。

#### 10. 旅行商问题 (Traveling Salesman Problem, TSP)
- **简介**: 一个推销员要访问n个城市，要求每个城市访问一次且仅一次，最后返回出发城市，求解最短的路线。
- **使用场景**: 电路板钻孔路径优化、物流配送路线规划、DNA测序。
- **优点**: 问题定义简单，是许多其他组合优化问题的基础。
- **缺点**: 典型的NP-hard问题，当城市数量稍多时，精确求解非常困难，通常使用启发式算法求解。
- **关键要素**: 城市（节点）集合、城市间的距离（或成本）矩阵。

#### 11. 车辆路径问题 (Vehicle Routing Problem, VRP)
- **简介**: TSP的扩展。一个或多个车队从一个或多个配送中心出发，向多个客户点送货，要求规划最优路线以达到总里程最短、成本最低等目标。
- **使用场景**: 快递配送、外卖送餐、公交路线规划、供应链物流。
- **优点**: 非常贴近现实世界的物流配送场景。
- **缺点**: 比TSP更复杂，也是NP-hard问题，通常需要复杂的启发式或元启发式算法求解。
- **关键要素**: 客户点、配送中心、车辆（容量、数量）、时间窗、路径成本。

#### 12. 遗传算法 (Genetic Algorithm, GA)
- **简介**: 模拟自然选择和遗传学机制的全局优化启发式算法。
- **使用场景**: 求解复杂的NP-hard问题（如TSP, VRP）、函数优化、机器学习中的超参数调优。
- **优点**: 全局搜索能力强，不易陷入局部最优；不依赖问题的梯度信息。
- **缺点**: 参数设置对性能影响大；可能“早熟”；收敛速度慢，无法保证找到最优解。
- **关键要素**: 基因编码、适应度函数、选择、交叉、变异。

#### 13. 模拟退火 (Simulated Annealing, SA)
- **简介**: 基于物理退火过程的随机优化算法。以一定概率接受比当前解差的解，从而跳出局部最优。
- **使用场景**: 求解大规模组合优化问题，如VLSI设计、TSP。
- **优点**: 理论基础坚实，实现简单，全局寻优能力强。
- **缺点**: 收敛速度慢，参数（初始温度、降温速率）设置敏感。
- **关键要素**: 初始解、新解生成机制、Metropolis接受准则、退火调度（降温策略）。

#### 14. 蚁群算法 (Ant Colony Optimization, ACO)
- **简介**: 模拟蚂蚁觅食过程中通过信息素进行通信的群体智能算法，主要用于在图中寻找最优路径。
- **使用场景**: TSP、VRP、网络路由问题。
- **优点**: 正反馈机制使其收敛速度快，具有良好的分布式计算潜力。
- **缺点**: 容易出现停滞现象（所有蚂蚁都走同一条路径），参数设置复杂。
- **关键要素**: 信息素更新规则、启发式信息（如距离）、路径构建策略。

#### 15. 粒子群算法 (Particle Swarm Optimization, PSO)
- **简介**: 模拟鸟群觅食行为的群体智能优化算法。每个粒子代表一个潜在解，通过追随个体历史最优和群体历史最优来更新自身的位置和速度。
- **使用场景**: 函数优化、神经网络训练、模糊系统控制。
- **优点**: 算法简单，参数少，易于实现，收敛速度快。
- **缺点**: 容易早熟，陷入局部最优，在处理离散优化问题时需要特殊设计。
- **关键要素**: 粒子（位置、速度）、个体最优解（pBest）、全局最优解（gBest）、速度和位置更新公式。

### **评价与决策类模型 (Evaluation & Decision Models)**

#### 16. 层次分析法 (AHP)
- **简介**: 一种将决策者的思维过程层次化、数量化的决策分析方法。它将复杂问题分解为目标、准则、方案等层次，通过两两比较的方式确定各元素的相对权重。
- **使用场景**: 方案选择、绩效评估、资源分配优先级排序。
- **优点**: 思路清晰，能处理定性与定量相结合的指标，逻辑性强，简单易用。
- **缺点**: **主观性过强**，判断矩阵的构建完全依赖专家经验。当准则层指标过多时，一致性检验难以通过。
- **关键要素**: 构建层次结构模型、构造判断矩阵、计算权重向量、一致性检验。

#### 17. 网络分析法 (Analytic Network Process, ANP)
- **简介**: AHP的扩展，ANP放弃了层次结构中元素之间严格的支配关系，考虑了网络中各元素（包括同层元素）之间的相互依赖和反馈。
- **使用场景**: 复杂的战略决策、政策制定，其中各因素相互影响（例如，经济发展、环境保护和社会稳定）。
- **优点**: 能更真实地反映复杂决策系统中各元素间的相互作用，模型结构更灵活。
- **缺点**: 模型构建和计算比AHP复杂得多，判断矩阵的数量大大增加，主观性问题依然存在。
- **关键要素**: 控制层、网络层、元素集、超矩阵（Supermatrix）。

#### 18. TOPSIS法 (Technique for Order of Preference by Similarity to Ideal Solution)
- **简介**: 通过检测评价对象与最优解（正理想解）、最劣解（负理想解）的距离来进行排序的方法。
- **使用场景**: 多属性、多方案的评价排序，如供应商选择、项目投资决策。
- **优点**: 原理简单直观，计算方便，对样本量和数据分布无严格限制。
- **缺点**: 需要对数据进行正向化和归一化。权重的确定对结果影响巨大，常需结合AHP或熵权法。
- **关键要素**: 决策矩阵、正向化、归一化、加权、计算与正负理想解的距离、计算相对贴近度。

#### 19. VIKOR法
- **简介**: 一种多准则决策中的折衷排序方法，其核心在于最大化群体效用（整体满意度）和最小化个体遗憾（最不满意的程度）。
- **使用场景**: 当决策者需要在相互冲突的准则之间寻找一个折衷方案时，如在成本、质量和速度之间权衡。
- **优点**: 提供了一个妥协解，更符合现实决策中的权衡思想。
- **缺点**: 计算比TOPSIS复杂，决策机制系数v的选择有一定主观性。
- **关键要素**: 正负理想解、群体效用S、个体遗憾R、利益比率Q。

#### 20. ELECTRE (ELimination Et Choix Traduisant la REalité)
- **简介**: 一类基于“超越关系”的排序方法。它通过成对比较方案，判断一个方案是否“不差于”另一个方案。
- **使用场景**: 适用于决策者偏好不明确、数据不精确或定性的决策问题。
- **优点**: 能处理不确定性和模糊性，不需要将所有指标转化为单一得分。
- **缺点**: 结果可能是部分排序甚至是不可比的，理解和实现相对复杂。
- **关键要素**: 协调指数、不协调指数、阈值、超越关系。

#### 21. PROMETHEE (Preference Ranking Organization METHod for Enrichment of Evaluations)
- **简介**: 一种基于优先函数的排序方法。通过为每个准则定义一个优先函数，来量化一个方案优于另一个方案的程度。
- **使用场景**: 环境管理、项目选择、金融投资等领域的排序问题。
- **优点**: 比ELECTRE更易于理解和使用，参数设置灵活，可以直观地看到每个方案的“正流”（优于其他方案的程度）和“负流”（劣于其他方案的程度）。
- **缺点**: 需要为每个准则选择合适的优先函数类型和参数。
- **关键要素**: 优先函数、优先指数、正向流、负向流、净流。

#### 22. 熵权法 (Entropy Weight Method, EWM)
- **简介**: 一种完全客观的指标权重确定方法。根据指标数据的变异程度来赋权，差异越大，信息熵越小，权重越高。
- **使用场景**: 在综合评价模型（如TOPSIS）中，为各评价指标提供客观权重，以替代主观赋权。
- **优点**: **完全客观**，排除了人为因素的干扰，计算过程简单。
- **缺点**: 只依赖于数据的离散程度，有时会产生与常识相悖的权重。
- **关键要素**: 数据归一化、计算信息熵、计算信息效用值（或差异系数）、确定权重。

#### 23. CRITIC法 (CRiteria Importance Through Intercriteria Correlation)
- **简介**: 一种比熵权法更全面的客观赋权法。它同时考虑了两个方面：指标内部的变异性（对比强度）和指标之间的冲突性（相关性）。
- **使用场景**: 指标间存在较强相关性的多属性决策问题。
- **优点**: 比熵权法考虑得更周全，既考虑了指标自身的信息量，也考虑了指标之间的关系。
- **缺点**: 计算相对熵权法复杂一些。
- **关键要素**: 对比强度（标准差）、指标冲突性（相关系数）、信息量计算。

#### 24. 模糊综合评价 (Fuzzy Comprehensive Evaluation)
- **简介**: 基于模糊数学理论的一种综合评价方法。用于处理评价指标和评语标准模糊不清的问题。
- **使用场景**: 满意度评价（如“满意”、“较满意”、“一般”）、环境质量评价、教师教学质量评价。
- **优点**: 非常适合处理定性指标的量化评估，能较好地反映评价的模糊性。
- **缺点**: 隶属函数的确定和权重矢量的计算带有一定主观性。
- **关键要素**: 因素集（评价指标）、评语集、隶属度矩阵、权重向量、模糊合成运算。

#### 25. 灰色关联分析 (Grey Relational Analysis, GRA)
- **简介**: 根据序列曲线几何形状的相似程度来判断因素之间关联度大小的一种方法。
- **使用场景**: 系统分析，找出影响某个主要目标的关键因素。例如，分析影响地区经济发展的几个主要因素哪个最重要。
- **优点**: 对数据量和分布没有要求，计算量小，简单易行。
- **缺点**: 需要确定一个“参考序列”（理想的最优序列），关联度的排序结果依赖于分辨系数的选择。
- **关键要素**: 参考序列、比较序列、数据无量纲化、灰色关联系数、关联度。

#### 26. DEMATEL (Decision Making Trial and Evaluation Laboratory)
- **简介**: 一种通过图论和矩阵工具来识别和分析复杂系统中各因素间因果关系的系统分析方法。
- **使用场景**: 识别复杂问题中的核心因素和根本原因。例如，分析影响供应链中断的各种风险因素，并找出核心风险源。
- **优点**: 能清晰地揭示系统中各因素之间的直接和间接影响关系，并区分出原因因素和结果因素。
- **缺点**: 需要专家打分来构建初始直接影响矩阵，有主观性。
- **关键要素**: 直接影响矩阵、规范化影响矩阵、综合影响矩阵、计算影响度与被影响度、中心度与原因度。

#### 27. 数据包络分析 (Data Envelopment Analysis, DEA)
- **简介**: 一种用于评价具有相同类型的多输入、多输出的决策单元（DMU）相对效率的非参数方法。
- **使用场景**: 评价医院、银行、学校、港口等公共部门或服务行业的运营效率。
- **优点**: 无需预设生产函数形式，能处理多输入多输出，评价结果只区分“相对有效”和“无效”。
- **缺点**: 结果对异常值敏感，评价结果是相对效率而非绝对效率。
- **关键要素**: 决策单元（DMU）、输入指标、输出指标、选择合适的DEA模型（如CCR, BCC）。

#### 28. 成本效益分析 (Cost-Benefit Analysis, CBA)
- **简介**: 通过比较一个项目或决策的总成本与总效益，来评估其可行性与价值的方法。
- **使用场景**: 政府公共项目投资决策（如修路、建大坝）、企业新项目评估。
- **优点**: 提供了一个清晰的决策标准（效益是否大于成本），思路直观。
- **缺点**: **难点在于将所有效益和成本都货币化**，尤其是社会效益、环境影响等无形价值。
- **关键要素**: 识别所有成本和效益、量化和货币化、折现（考虑时间价值）、计算净现值（NPV）或效益成本比（BCR）。

#### 29. 博弈论模型 (Game Theory Models)
- **简介**: 研究多个决策主体（参与人）在策略选择上相互作用、相互影响时的决策问题及均衡。
- **使用场景**: 市场竞争策略分析（寡头定价）、国际关系、拍卖设计、公共资源管理（公地悲剧）。
- **优点**: 提供了一个分析冲突与合作的强大理论框架。
- **缺点**: 对参与人的“理性”假设过强，现实中人的行为复杂。
- **关键要素**: 参与人、策略集、支付函数、均衡（如纳什均衡）。

#### 30. 效用理论 (Utility Theory)
- **简介**: 描述和量化决策者在面对不确定性时的个人偏好和风险态度的理论。
- **使用场景**: 个人投资决策（风险厌恶、风险中性、风险偏好）、保险购买决策。
- **优点**: 为不确定性下的理性决策提供了数学基础。
- **缺点**: 效用函数是个人的、主观的，难以精确测量。
- **关键要素**: 效用函数、期望效用。

### **统计与概率模型 (Statistics & Probability Models)**

#### 31. 描述性统计 (Descriptive Statistics)
- **简介**: 使用图表（如直方图、箱线图）和统计量（如均值、中位数、方差、标准差）来概括和描述数据集的基本特征。
- **使用场景**: 任何数据分析项目的第一步，用于了解数据分布、中心趋势、离散程度和异常值。
- **优点**: 直观、简单，是理解数据的基础。
- **缺点**: 只能描述样本本身，不能用于推断总体。
- **关键要素**: 集中趋势（均值、中位数、众数）、离散程度（方差、标准差、极差）、分布形状（偏度、峰度）。

#### 32. 假设检验 (Hypothesis Testing)
- **简介**: 一种统计推断方法，用于判断样本与总体、或样本与样本之间的差异是由抽样误差引起还是本质差异所致。
- **使用场景**: 检验新药是否比旧药更有效、判断两个地区居民的收入是否有显著差异。
- **优点**: 提供了一套科学的、可重复的决策框架来验证猜想。
- **缺点**: 结果可能出现第一类错误（弃真）和第二类错误（取伪），结论的可靠性依赖于显著性水平α的选择。
- **关键要素**: 原假设(H0)、备择假设(H1)、检验统计量、P值、显著性水平(α)。

#### 33. t检验 (t-test)
- **简介**: 用于检验两个正态分布总体的均值是否存在显著差异。
- **使用场景**:
  - **单样本t检验**：检验某班级的平均身高是否显著高于全国平均水平。
  - **独立样本t检验**：检验A、B两种教学方法下学生成绩是否有显著差异。
  - **配对样本t检验**：检验同一组病人在服药前后的血压是否有显著变化。
- **优点**: 应用广泛，是比较两组均值最常用的方法。
- **缺点**: 要求数据服从正态分布（或近似正态），且两组数据方差齐性（对于独立样本t检验）。
- **关键要素**: 样本均值、样本标准差、样本量。

#### 34. 方差分析 (Analysis of Variance, ANOVA)
- **简介**: t检验的扩展，用于检验两个或两个以上样本的均值是否存在显著差异。
- **使用场景**: 比较三种不同化肥对农作物产量的影响、分析不同学历人群的平均薪资差异。
- **优点**: 能同时比较多个组的均值，避免了进行多次t检验带来的错误率累积。
- **缺点**: 只能告诉我们“至少有一组与其他组不同”，但不能指出具体是哪几组之间存在差异（需借助事后检验）。要求各组数据独立、正态、方差齐性。
- **关键要素**: F统计量、组间平方和、组内平方和。

#### 35. 卡方检验 (Chi-Squared Test)
- **简介**: 用于检验两个或多个分类变量之间是否相互独立的非参数检验。
- **使用场景**: 分析吸烟（是/否）与肺癌（是/否）之间是否存在关联、判断不同血型的人在星座分布上是否有差异。
- **优点**: 应用简单，不要求数据分布，专门用于分类数据的关联性分析。
- **缺点**: 要求样本量不能太小（通常要求期望频数>5）。
- **关键要素**: 观测频数、期望频数、列联表（交叉表）、卡方统计量。

#### 36. 相关性分析 (Correlation Analysis)
- **简介**: 衡量两个或多个连续变量之间线性关系强度和方向的统计方法。
- **使用场景**: 分析身高与体重、广告投入与销售额、气温与冰淇淋销量之间的关系。
- **优点**: 简单直观，相关系数易于解释。
- **缺点**: **相关不等于因果**。只能度量线性关系，无法捕捉非线性关系。
- **关键要素**: Pearson相关系数（用于正态分布的连续变量）、Spearman等级相关系数（用于有序或非正态变量）、Kendall's Tau相关系数。

#### 37. 主成分分析 (Principal Component Analysis, PCA)
- **简介**: 一种数据降维技术，通过线性变换将原始的多个相关变量，转化为少数几个互不相关的综合变量（主成分），同时尽可能多地保留原始数据的信息。
- **使用场景**:
  - **数据降维与可视化**：将高维数据降到2维或3维进行可视化。
  - **信息压缩**：用少数几个主成分代替大量原始变量进行后续建模。
  - **解决多重共线性**：在回归分析中，当自变量高度相关时，可以用主成分代替原始自变量。
- **优点**: 无需参数设置，客观有效，能消除变量间的相关性。
- **缺点**: 降维后得到的主成分的实际意义可能难以解释。
- **关键要素**: 协方差矩阵（或相关矩阵）、特征值、特征向量、贡献率。

#### 38. 因子分析 (Factor Analysis, FA)
- **简介**: 也是一种降维方法，但其目的不同于PCA。它旨在从多个原始观测变量中，提取出潜在的、不可观测的“公共因子”或“潜在变量”，以解释原始变量之间的相关性。
- **使用场景**: 心理学（从多个问卷题目中提取“外向性”、“宜人性”等潜在人格特质）、市场研究（从多个产品评价中提取“性价比”、“外观设计”等潜在因子）。
- **优点**: 侧重于揭示变量间的内在结构和关系，解释性比PCA强。
- **缺点**: 模型比PCA复杂，需要指定因子数量，结果可能存在旋转不唯一的问题。
- **关键要素**: 因子载荷、公共因子、特殊因子、因子旋转。

#### 39. 线性回归 (Linear Regression)
- **简介**: 用线性关系模型来拟合一个或多个自变量（特征）与一个连续因变量（目标）之间的关系。
- **使用场景**: 房价预测（根据面积、位置、房龄等预测房价）、销售额预测。
- **优点**: 模型简单，易于理解和解释，是许多复杂模型的基础。
- **缺点**: 只能拟合线性关系，对异常值敏感，要求自变量间无多重共线性。
- **关键要素**: 回归系数、截距、残差、决定系数R²。

#### 40. 多项式回归 (Polynomial Regression)
- **简介**: 线性回归的扩展，通过引入自变量的高次项（如x², x³）来拟合非线性关系。
- **使用场景**: 当散点图显示变量间存在明显的曲线关系时。
- **优点**: 能拟合非线性数据，扩展了线性回归的应用范围。
- **缺点**: 阶数选择困难，高阶多项式容易导致过拟合。
- **关键要素**: 多项式的阶数。

#### 41. 岭回归/Lasso回归 (Ridge/Lasso Regression)
- **简介**: 带有正则化项的线性回归，用于处理多重共线性问题和进行特征选择。
- **使用场景**: 当数据集中自变量数量多且彼此高度相关时。
- **优点**: **岭回归**能有效处理多重共线性；**Lasso回归**能进行特征选择，将不重要的变量系数压缩至0。
- **缺点**: 正则化参数λ的选择对模型性能至关重要。
- **关键要素**: 正则化参数（λ或α）。

#### 42. 逻辑回归 (Logistic Regression)
- **简介**: 用于预测一个二分类（或多分类）因变量的概率。
- **使用场景**: 信用评分（判断是否违约）、医疗诊断（判断是否患病）、点击率预测。
- **优点**: 输出结果是概率，易于理解；模型简单高效，解释性强。
- **缺点**: 拟合能力有限，无法处理复杂的非线性关系。
- **关键要素**: Sigmoid函数、对数似然损失函数。

#### 43. 泊松分布/回归 (Poisson Distribution/Regression)
- **简介**: 泊松分布用于描述单位时间（或空间）内随机事件发生的次数。泊松回归则用于预测这类“计数”数据。
- **使用场景**: 预测一小时内到达某呼叫中心的电话数、预测某路段一天内的交通事故数。
- **优点**: 专门用于对计数数据建模。
- **缺点**: 要求事件的发生是独立的，且平均发生率恒定。
- **关键要素**: 事件发生率（λ）。

#### 44. 贝叶斯定理/网络 (Bayesian Theorem/Network)
- **简介**: 贝叶斯定理描述了在获得新证据后，如何更新一个事件的先验概率以得到后验概率。贝叶斯网络则是将变量及其条件依赖关系表示为一个有向无环图。
- **使用场景**: 垃圾邮件过滤、医疗诊断（根据症状更新患病概率）、风险分析。
- **优点**: 能有机地融合先验知识和数据，适合增量学习。
- **缺点**: 先验概率的选择对结果影响大且带有主观性。当变量多时，网络结构和条件概率表非常复杂。
- **关键要素**: 先验概率、后验概率、似然、条件概率表。

#### 45. 马尔可夫链 (Markov Chain)
- **简介**: 一种数学模型，用于描述一个系统从一个状态转移到另一个状态的随机过程。其核心特性是“无后效性”，即未来状态只取决于当前状态，与过去状态无关。
- **使用场景**: 预测天气状态的转移、分析顾客在不同品牌间的转换行为、网页排名（PageRank算法的基础）。
- **优点**: 模型结构简单，能很好地描述具有状态转移特性的系统。
- **缺点**: “无后效性”的假设在现实中可能过于苛刻。
- **关键要素**: 状态空间、状态转移概率矩阵。

### **预测与时序模型 (Prediction & Time Series Models)**

#### 46. 移动平均法 (Moving Average, MA)
- **简介**: 通过计算时间序列数据中最近N个周期的滚动平均值，来平滑数据并预测下一期的值。
- **使用场景**: 简单的短期销售预测、库存管理。
- **优点**: 非常简单，易于理解和计算。
- **缺点**: 对趋势变化反应滞后，无法处理趋势和季节性，预测能力有限。
- **关键要素**: 窗口大小N。

#### 47. 指数平滑 (Exponential Smoothing, ES)
- **简介**: 一种加权平均方法，对历史数据赋予递减的权重（越近的数据权重越高）。
- **使用场景**:
  - **简单指数平滑 (SES)**: 用于没有趋势和季节性的序列。
  - **Holt线性趋势法**: 用于有趋势但没有季节性的序列。
  - **Holt-Winters法**: 用于既有趋势又有季节性的序列。
- **优点**: 比移动平均更灵活，对近期数据更敏感，能处理趋势和季节性。
- **缺点**: 参数选择（平滑系数α, β, γ）对结果影响大。
- **关键要素**: 平滑系数（α, β, γ）、初始值。

#### 48. ARIMA模型 (Autoregressive Integrated Moving Average)
- **简介**: 经典的时间序列预测模型，它将一个非平稳的时间序列通过差分（Integrated）转化为平稳序列，然后用自回归（AR）和移动平均（MA）部分来描述该平稳序列。
- **使用场景**: 股票价格、经济指标（GDP、CPI）、交通流量等时间序列数据的预测。
- **优点**: 理论体系完善，是许多复杂时序模型的基础。
- **缺点**: 要求序列必须是平稳的（或可通过差分平稳），只能捕捉线性关系。
- **关键要素**: AR阶数(p)、差分阶数(d)、MA阶数(q)。

#### 49. SARIMA模型 (Seasonal ARIMA)
- **简介**: 季节性ARIMA模型，是ARIMA模型的扩展，增加了对数据中季节性变化的处理。
- **使用场景**: 零售销售额（有年度周期）、电力消耗（有日度和年度周期）、旅游人数等具有明显季节性的时间序列。
- **优点**: 能有效捕捉和预测序列中的季节性模式。
- **缺点**: 模型参数更多（P, D, Q, m），定阶更复杂。
- **关键要素**: 非季节性参数(p, d, q)和季节性参数(P, D, Q, m)。

#### 50. ARCH/GARCH模型 (Autoregressive Conditional Heteroskedasticity)
- **简介**: 用于建模和预测时间序列波动性（方差）的模型。它认为序列当前的方差依赖于过去的残差平方。GARCH是其扩展。
- **使用场景**: 金融时间序列分析，如股票收益率的波动性预测、风险管理（计算VaR）。
- **优点**: 能很好地刻画金融市场中的“波动聚集”现象（即大的波动后倾向于跟随着大的波动）。
- **缺点**: 模型较为复杂，主要用于波动率建模而非均值预测。
- **关键要素**: ARCH项的阶数(p)、GARCH项的阶数(q)。

#### 51. 灰色预测 (GM(1,1))
- **简介**: 通过对少量原始数据进行累加生成新的、规律性更强的序列，并对新序列建立微分方程模型来进行预测。
- **使用场景**: “少数据”（通常4-10个数据点）、“贫信息”情况下的短期趋势预测。如预测某个新兴产品的短期产量。
- **优点**: **对小样本数据效果好**，不要求数据分布，计算简单。
- **缺点**: 只适用于近似指数增长的序列，中长期预测精度差。
- **关键要素**: 累加生成（AGO）、背景值构造、微分方程参数求解、累减还原。

#### 52. Prophet模型
- **简介**: 由Facebook开源的一个易用且强大的时间序列预测工具。它将时间序列分解为趋势项、季节性项和节假日项。
- **使用场景**: 商业预测，尤其是具有多重季节性（年、周、日）和节假日效应的数据，如网站流量、销售预测。
- **优点**: 使用简单，无需深厚的时序知识；能自动处理节假日效应和季节性；对缺失值和异常值稳健。
- **缺点**: “自动化”的代价是可解释性不如ARIMA等传统模型强，更像一个“黑箱”。
- **关键要素**: 趋势模型（分段线性或逻辑回归）、季节性（傅里叶级数）、节假日列表。

#### 53. 向量自回归(VAR) (Vector Autoregression)
- **简介**: 一种多变量时间序列预测模型。它将系统中的每个变量都视为所有变量的滞后项的函数，从而捕捉变量间的动态影响。
- **使用场景**: 宏观经济分析，如分析利率、通货膨胀率和GDP增长率之间的相互动态关系。
- **优点**: 能捕捉多个时间序列之间的联动关系，不仅能预测，还能做脉冲响应分析和格兰杰因果检验。
- **缺点**: 模型所需的参数数量随变量和滞后阶数的增加而爆炸式增长，容易出现过拟合。
- **关键要素**: 变量、滞后阶数。

#### 54. 状态空间模型 (State-Space Models)
- **简介**: 一种非常灵活和通用的时间序列建模框架。它假设观测到的时间序列是由一个不可观测的、潜在的“状态”变量生成的。
- **使用场景**: 几乎所有时间序列模型（如ARIMA, 指数平滑）都可以表示为状态空间形式。也用于信号处理、动态系统控制。
- **优点**: 框架极具通用性，能处理缺失值，并能有机地融合多种模式（趋势、季节性、周期性）。
- **缺点**: 模型定义和估计相对复杂。
- **关键要素**: 状态方程（描述潜在状态如何演化）、观测方程（描述如何从潜在状态生成观测值）。

#### 55. 卡尔曼滤波 (Kalman Filter)
- **简介**: 在线性高斯状态空间模型假设下，用于估计动态系统最优状态的递推算法。它通过“预测”和“更新”两个步骤，在含噪声的测量数据中不断修正对系统状态的估计。
- **使用场景**: 导航系统（如GPS）、无人机姿态估计、信号处理、经济学预测。
- **优点**: 计算高效（是递推算法），在线实时应用效果好，理论最优。
- **缺点**: 只适用于线性和高斯噪声的系统。对于非线性系统，需要使用扩展卡尔曼滤波（EKF）或无迹卡尔曼滤波（UKF）。
- **关键要素**: 状态转移矩阵、观测矩阵、过程噪声协方差、测量噪声协方差。

#### 56. 灾变理论 (Catastrophe Theory)
- **简介**: 研究系统从一个稳定状态到另一个稳定状态的“突变”或“跳跃”现象的数学理论。
- **使用场景**: 用于解释和预测如桥梁的突然坍塌、市场的突然崩溃、细胞的分化、人的情绪从平静到暴怒的转变等不连续的突变行为。
- **优点**: 为理解“渐变导致突变”的现象提供了数学框架。
- **缺点**: 偏向于定性解释，定量预测能力有限，模型应用难度大。
- **关键要素**: 状态变量、控制变量、势函数、奇点。

### **机器学习模型 (Machine Learning Models)**

#### 57. K-Means聚类 (K-Means Clustering)
- **简介**: 一种无监督学习算法，旨在将给定的数据集自动划分为K个类别（簇）。
- **使用场景**: 客户分群、图像分割。
- **优点**: 算法简单，处理大规模数据集时效率高。
- **缺点**: 需要预先指定簇的数量K；对初始簇中心敏感；对非球形的簇和异常值处理效果不佳。
- **关键要素**: K值、距离度量（通常是欧氏距离）、簇中心。

#### 58. 层次聚类 (Hierarchical Clustering)
- **简介**: 通过构建一个树状的聚类结构（谱系图）来进行聚类。分为凝聚型（自下而上）和分裂型（自上而下）。
- **使用场景**: 生物学中的物种分类、社交网络分析。
- **优点**: 无需预设聚类数，聚类结果以树状图呈现，易于理解。
- **缺点**: 计算复杂度高（至少O(n²)），对大数据集不适用。
- **关键要素**: 距离度量、簇间合并/分裂的准则（如ward, average, complete linkage）。

#### 59. DBSCAN (Density-Based Spatial Clustering of Applications with Noise)
- **简介**: 一种基于密度的聚类算法。它将足够“拥挤”的区域划为簇，并能发现任意形状的簇，同时将稀疏区域的数据点识别为噪声。
- **使用场景**: 识别任意形状的聚类、处理含噪声的数据、空间数据分析。
- **优点**: 无需指定簇数，能发现任意形状的簇，对噪声不敏感。
- **缺点**: 对密度变化大的数据集效果不佳，对高维数据效果差（维度灾难）。
- **关键要素**: 邻域半径(ε)、最小点数(MinPts)。

#### 60. 支持向量机 (Support Vector Machine, SVM)
- **简介**: 一种强大的监督学习模型，用于分类和回归。其核心思想是在特征空间中找到一个能将不同类别样本分隔开的最佳超平面，使得两类样本到该超平面的间隔（Margin）最大。
- **使用场景**: 文本分类、图像识别、生物信息学。
- **优点**: 在高维空间中表现优异，特别适合小样本、非线性问题；泛化能力强。
- **缺点**: 对大规模数据集训练速度慢；对缺失数据敏感；核函数和参数的选择对结果影响很大。
- **关键要素**: 核函数（线性、多项式、RBF）、惩罚参数C、间隔（Margin）。

#### 61. K-近邻 (K-Nearest Neighbors, KNN)
- **简介**: 一种非常简单的监督学习算法。对于一个新的样本，它通过在训练集中寻找离它最近的K个邻居，并根据这K个邻居的类别进行投票（分类）或取平均值（回归）来做出预测。
- **使用场景**: 分类问题、推荐系统（找到相似的用户或物品）。
- **优点**: 思想简单，无需训练阶段，易于实现。
- **缺点**: 预测时计算量大（需要计算与所有训练样本的距离）；对样本不均衡的数据敏感；对K值的选择和距离度量敏感。
- **关键要素**: K值、距离度量（如欧氏距离、曼哈顿距离）。

#### 62. 朴素贝叶斯 (Naive Bayes)
- **简介**: 基于贝叶斯定理和特征条件独立性假设的分类器。它“朴素”地假设所有特征之间都是相互独立的。
- **使用场景**: 文本分类（如垃圾邮件过滤）、情感分析。
- **优点**: 算法简单，计算高效，在数据量较小的情况下依然表现良好。
- **缺点**: “特征条件独立”的假设在现实中往往不成立，这会影响其预测精度。
- **关键要素**: 先验概率、条件概率。

#### 63. 决策树 (Decision Tree)
- **简介**: 一种树状结构的预测模型，其中每个内部节点代表对一个特征的测试，每个分支代表一个测试输出，每个叶节点代表一个类别标签（分类树）或一个数值（回归树）。
- **使用场景**: 分类问题、医疗诊断。
- **优点**: **模型直观，易于解释**，符合人类的决策思维。能够处理数值型和类别型数据。
- **缺点**: **非常容易过拟合**，生成的树可能过于复杂。对输入数据中的微小变化很敏感。
- **关键要素**: 特征选择（如信息增益、基尼不纯度）、树的生成、剪枝（防止过拟合）。

#### 64. 随机森林 (Random Forest, RF)
- **简介**: 一种集成学习算法，通过构建并组合大量的决策树来做出预测。它通过对样本和特征的随机采样，解决了单棵决策树容易过拟合的问题。
- **使用场景**: 金融风控、医疗诊断、推荐系统等各种高精度的分类和回归任务。
- **优点**: 预测精度高，泛化能力强，能有效防止过拟合；能处理高维数据并评估特征重要性。
- **缺点**: 模型是“黑箱”，解释性差；对于某些噪声较大的数据容易过拟合。
- **关键要素**: 决策树数量、自助采样法（Bootstrap）、随机特征选择。

#### 65. 梯度提升机 (Gradient Boosting Machine, GBM)
- **简介**: 一种集成学习算法，它通过迭代地训练一系列弱学习器（通常是决策树），每一棵树都致力于修正前面所有树留下的残差（误差）。
- **使用场景**: 分类和回归任务，特别是在追求高精度时。
- **优点**: 预测精度通常很高。
- **缺点**: 训练过程是串行的，难以并行，速度较慢；对参数设置敏感，容易过拟合。
- **关键要素**: 损失函数、学习率、树的数量和深度。

#### 66. XGBoost/LightGBM
- **简介**: 梯度提升决策树（GBDT/GBM）的高效工程实现，通过各种优化（如二阶泰勒展开、并行化、缓存优化等）大大提升了训练速度和性能。
- **使用场景**: 几乎所有的结构化数据（表格数据）的分类和回归任务，是数据科学竞赛中的“大杀器”。
- **优点**: 精度极高；训练速度快（尤其是LightGBM）；支持并行计算；内置交叉验证和正则化，能有效控制过拟合。
- **缺点**: 参数众多，调参复杂；模型可解释性差。
- **关键要素**: 学习率、树的数量、树的深度、正则化项。

#### 67. 人工神经网络(Artificial Neural Network, ANN)
- **简介**: 模拟人脑神经元网络结构的计算模型。由大量的、相互连接的“神经元”（节点）组成，通过学习数据中的模式来进行预测。
- **使用场景**: 模式识别、函数逼近、分类与回归。
- **优点**: 学习能力和非线性拟合能力极强。
- **缺点**: “黑箱”模型，难以解释；容易过拟合；需要大量数据和计算资源进行训练。
- **关键要素**: 网络结构（层数、神经元数）、激活函数、损失函数、优化器。

#### 68. 卷积神经网络 (Convolutional Neural Network, CNN)
- **简介**: 一种专门处理具有网格状拓扑结构数据（如图像）的深度学习模型。它通过卷积层和池化层，能够有效地提取数据中的空间层次特征。
- **使用场景**: **图像识别**、物体检测、图像分割、人脸识别。
- **优点**: 权值共享和局部连接的特性大大减少了模型参数，使其在处理高维图像时非常高效且强大。
- **缺点**: 主要适用于网格状数据，对于序列数据或表格数据效果不佳。
- **关键要素**: 卷积层、池化层、激活函数、全连接层。

#### 69. 循环神经网络 (Recurrent Neural Network, RNN)
- **简介**: 一种专门处理序列数据的神经网络。其网络结构中包含“循环”连接，使得信息可以在时间步之间传递，从而让模型具有“记忆”功能。
- **使用场景**: 自然语言处理（文本生成、机器翻译）、语音识别、时间序列预测。
- **优点**: 能处理变长的序列输入，并能捕捉序列中的时间依赖关系。
- **缺点**: 存在“长期依赖”问题和梯度消失/爆炸问题，难以学习到序列中距离较远的信息。
- **关键要素**: 循环单元、隐藏状态。

#### 70. LSTM/GRU (Long Short-Term Memory / Gated Recurrent Unit)
- **简介**: RNN的两种流行变体，专门为了解决RNN的长期依赖问题而设计。它们通过引入“门控机制”（如遗忘门、输入门、输出门）来有选择地让信息通过，从而更好地学习长期模式。
- **使用场景**: 所有RNN适用的场景，但通常性能更好，是目前处理序列数据的标准模型。
- **优点**: 极大地缓解了梯度消失问题，能有效学习长距离依赖。
- **缺点**: 模型结构比RNN更复杂，计算成本更高。
- **关键要素**: 门控单元（遗忘门、输入门、输出门）。

#### 71. Transformer
- **简介**: 一种基于“自注意力机制”（Self-Attention）的深度学习模型，最初用于自然语言处理。它完全摒弃了RNN的循环结构，实现了完全并行的计算。
- **使用场景**: **自然语言处理**（机器翻译、文本摘要、问答系统，如BERT, GPT的基础）、计算机视觉。
- **优点**: 并行计算能力强，训练速度快；自注意力机制能更好地捕捉全局和长距离依赖。
- **缺点**: 模型巨大，需要极大的计算资源和数据量；对于特别长的序列，计算量呈平方级增长。
- **关键要素**: 自注意力机制、多头注意力、位置编码。

#### 72. Q-Learning
- **简介**: 一种经典的、无模型的强化学习算法。它让一个智能体（Agent）在环境中不断尝试，通过奖励和惩罚来学习一张Q表（Quality Table），这张表告诉智能体在每个状态下执行哪个动作能获得最大的长期回报。
- **使用场景**: 简单的路径规划、游戏AI（如走迷宫）。
- **优点**: 算法简单，易于理解，是强化学习的入门基础。
- **缺点**: 只能处理离散的、有限的状态和动作空间，对于状态空间大的问题会产生“维度灾难”。
- **关键要素**: 状态、动作、奖励、Q表、学习率(α)、折扣因子(γ)。

#### 73. Agent-Based Modeling (ABM)
- **简介**: 一种通过模拟大量自主智能体（Agent）的行为及其相互作用，来观察和研究整个系统宏观现象的建模方法。
- **使用场景**: 模拟传染病传播、交通流、金融市场动态、社会舆论形成等复杂系统。
- **优点**: 自下而上的建模思路，能捕捉到由简单个体行为涌现出的复杂宏观现象，非常直观。
- **缺点**: 模型结果难以进行严格的数学验证；对Agent行为规则的设定非常敏感。
- **关键要素**: 智能体（Agent）、环境（Environment）、规则（Rules）。

### **图与网络模型 (Graph & Network Models)**

#### 74. Dijkstra算法
- **简介**: 一种经典的单源最短路径算法，用于计算图中一个节点到所有其他节点的最短路径。
- **使用场景**: 地图导航（计算两点间最快路线）、网络路由（寻找最优路径）。
- **优点**: 算法思想是贪心策略，直观且高效。
- **缺点**: **不能处理带有负权重边的图**。
- **关键要素**: 起点、邻接表/矩阵、距离数组。

#### 75. Floyd-Warshall算法
- **简介**: 一种计算图中任意两点间最短路径的算法。
- **使用场景**: 需要知道图中所有节点对之间最短路径的场景，如社交网络中任意两人之间的“距离”。
- **优点**: 能够处理带有负权重边的图（但不能有负权环），算法实现简单。
- **缺点**: 时间复杂度高（O(n³)），不适用于大规模图。
- **关键要素**: 动态规划思想、距离矩阵。

#### 76. A* 搜索算法 (A* Search Algorithm)
- **简介**: 一种在图中寻找最短路径的启发式搜索算法。它在Dijkstra算法的基础上，增加了一个启发式函数（预估当前点到终点的距离），从而能更“智能”地朝向终点搜索。
- **使用场景**: 游戏AI中的角色寻路、地图应用中的路径规划。
- **优点**: 通常比Dijkstra算法效率高得多，因为它是有方向性地搜索。
- **缺点**: 启发式函数的质量直接决定了算法的效率和准确性。
- **关键要素**: g(n)（从起点到当前节点的实际代价）、h(n)（从当前节点到终点的预估代价）、f(n) = g(n) + h(n)。

#### 77. Prim/Kruskal算法
- **简介**: 两种经典的最小生成树（Minimum Spanning Tree, MST）算法。目标是在一个加权无向图中，找到一棵连接所有节点的、总权重最小的树。
- **使用场景**: 网络建设（如铺设电缆、管道，使得总长度最短）、电路设计。
- **优点**: 都是贪心算法，实现简单，能保证找到最优解。**Prim**适合稠密图，**Kruskal**适合稀疏图。
- **缺点**: 只适用于无向图。
- **关键要素**: **Prim**: 维护一个已连接节点的集合，每次选择离集合最近的节点加入。**Kruskal**: 按权重从小到大对所有边排序，依次加入，只要不形成环路即可。

#### 78. PageRank算法
- **简介**: 谷歌早期用于评估网页重要性的核心算法。它的基本思想是：一个网页被越多、越重要的其他网页链接，那么它本身也越重要。
- **使用场景**: 网页排名、社交网络中识别影响力大的用户、学术论文引用网络中识别重要文献。
- **优点**: 算法思想优雅，能有效衡量节点的“影响力”。
- **缺点**: 容易受到“链接农场”等作弊手段的攻击。
- **关键要素**: 链接关系、阻尼系数。

#### 79. 社区发现算法 (Community Detection)
- **简介**: 一类用于在复杂网络中识别出“社区”结构的算法。社区是指网络中一些节点的集合，这些节点内部连接紧密，而与外部节点的连接相对稀疏。
- **使用场景**: 社交网络分析（发现兴趣小组、朋友圈）、生物网络分析（识别功能模块）、推荐系统。
- **优点**: 能揭示网络的宏观结构，帮助理解网络功能。
- **缺点**: “社区”的定义本身模糊，不同算法可能得到完全不同的结果。
- **关键要素**: 模块度（Modularity）、Louvain算法、Girvan-Newman算法。

#### 80. 网络中心性分析 (Network Centrality)
- **简介**: 一组用于衡量网络中节点重要性或影响力的指标。
- **使用场景**:
  - **度中心性**: 识别网络中的“枢纽”（连接数最多的节点）。
  - **介数中心性**: 识别网络中的“桥梁”（位于许多其他节点对最短路径上的节点）。
  - **紧密中心性**: 识别网络中的“中心”（到所有其他节点的平均距离最短的节点）。
- **优点**: 提供了从不同角度量化节点重要性的方法。
- **缺点**: 计算复杂度可能很高（尤其是介数中心性）。
- **关键要素**: 邻接关系、最短路径。

#### 81. PERT/CPM (项目评估与审查技术/关键路径法)
- **简介**: 一套用于规划和管理大型复杂项目的技术，通过构建项目网络图来分析任务依赖关系和时间安排。
- **使用场景**: 建筑工程、软件开发、新产品研发等任何有明确开始和结束日期的项目。
- **优点**: 清晰地识别出项目中的“关键路径”（决定项目总工期的任务序列），帮助管理者集中资源、监控风险。
- **缺点**: 对任务时间的估计准确性要求高，对不确定性处理能力有限。
- **关键要素**: 活动（任务）、事件（里程碑）、持续时间、依赖关系、关键路径。
