前向传播（算输出）：
y = w * x + b    → y = 0.5
计算损失（越小越好）：
Loss = (y - t)^2   → Loss = 2.25
反向传播（求梯度）：
先算损失对 y 的导数：
dL/dy = 2 * (y - t)   → -1.5
再算损失对 w 和 b：
dL/dw = dL/dy * x   → -1.5
dL/db = dL/dy * 1   → -1.5
梯度下降（更新参数）：
w = w - lr * dL/dw     b = b - lr * dL/db
例如：学习率 lr = 0.1
更新后： w = 0.65 ， b = 0.15
步骤
1. 前向：计算 y
2. 算损失 Loss
3. 反向：求梯度
4. 更新：w, b
